# Password Generator 🔐

A simple password generator built with HTML, CSS, and JavaScript to generate random passwords quickly and conveniently.

## ✨ Features
- Random password generation
- Dynamic password display
- Copy password to clipboard
- Interactive buttons and user feedback

## 🛠️ Built With
- HTML5
- CSS3
- JavaScript (DOM Manipulation, Event Listeners, Arrays, Random Number Generation, and Clipboard API)

## 🚀 Getting Started
Clone the repository and open `index.html` in your browser.

```bash
git clone - https://github.com/Anika-Aktar/Password-generator.git
```
